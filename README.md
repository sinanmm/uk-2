# Bayshield International UK Website

A responsive, animated Next.js website inspired by the supplied porcelain tile website references.

## Pages

- `/` — Professional homepage
- `/tiles` — Interactive tile collection with filters, search, favourites and product modal
- `/about` — Bayshield International UK company and product information
- `/contact` — Contact details, quote form and WhatsApp links

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build for production

```bash
npm run build
npm start
```
